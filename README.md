# KyvenLab downloads

This repository hosts the public download page for **KyvenLab** and its Windows installers.

- Page: https://app-kyvenlab.kyvensoft.com.br (served by GitHub Pages from `main`)
- Installers: [Releases](https://github.com/Flodyz/kyvenlab-app/releases). The latest one is always at
  `https://github.com/Flodyz/kyvenlab-app/releases/latest/download/KyvenLab-setup.exe`.

The content of this repository is generated. The source of the page, the publish script and the app
itself live in the private KyvenLab repository; do not edit files here, the next publish replaces them.
